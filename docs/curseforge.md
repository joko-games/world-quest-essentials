# CurseForge page

The texts of the project page on CurseForge, kept here so that they follow the addon. When a feature worth showing is added, changed or removed, update them here, then paste them into the project settings on CurseForge. The description uses CurseForge's Markdown editor.

## Icon

The project icon is `art/icon.png`, the same drawing as the icon in the game (CC0, docs/development.md).

## Summary

The catchline shown under the name in search results and lists:

> Every Midnight world quest in one list beside the map, with search, filters and rewards on hover.

## Description

```markdown
# World Quest Essentials

Every world quest of Midnight you can do, in one short list beside the world map. Whether the map shows Quel'Thalas or Pandaria, the list is the same.

- **Search** by quest, zone or reward.
- **Filter** by reward: gear, gold, currency, reputation, items.
- **Sort** by type, value, name, zone or time left.
- **Hover** a line to see its rewards. **Click** sets the waypoint, **Shift-click** tracks it.

Nothing else, and no settings to learn. Bugs and ideas: [GitHub](https://github.com/star-racer/world-quest-essentials/issues).
```
